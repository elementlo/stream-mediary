# Mediary 0.1.0

This release adds in-app language switching and fixes Windows tray, font and layout issues.

## Highlights

- **Switch language without restarting.** Settings → Language offers System / 中文 / English. The entire interface re-renders in the chosen language the moment you pick it, and the choice persists across restarts.
- **Windows tray menu works again.** Right-clicking the tray icon now reliably opens the context menu (with "Quit"), even while the main window is hidden. The tray implementation was upgraded so the menu is shown natively instead of through a path that silently failed on a hidden window. Left click still restores the window.
- **Proper Chinese fonts on Windows.** Chinese text no longer falls back to the serif SimSun face that clashed with the sans-serif UI; it now renders in the platform-native sans-serif (Microsoft YaHei).
- **Speed readout aligned.** On download cards, the speed is flush right again instead of stranded mid-row when an ETA is shown.

The desktop archives are not notarized or code signed. macOS and Windows may show an operating-system warning on first launch.

Verify downloads with `SHA256SUMS.txt` from this release. Signed video URLs may expire, and some sources require browser-only authorization. DRM-protected streams are not supported.
