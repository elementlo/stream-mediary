# Mediary 0.0.9

This release improves the Windows handoff from the [Video Stream Link Detector](https://github.com/elementlo/IDM-shell-extension) extension and the download preview.

## Highlights

- Browser links now open in the existing Windows Mediary window. A second download can be sent while the first window is already running.
- The preview shows your configured default save directory. Choosing another directory updates the destination and free-space check without parsing the video again.
- The companion extension now uses a captured signed PNG stream URL when available, and its in-page controls appear only while hovering over a video. Clicking outside the menu closes it. Reload the unpacked extension to get these changes.

## Downloads

| Platform | Asset | Notes |
| --- | --- | --- |
| Android arm64 | `Mediary-android-arm64-v8a.apk` | Install on supported Android devices. |
| Android 32-bit ARM | `Mediary-android-armeabi-v7a.apk` | Install on supported Android devices. |
| macOS | `Mediary-macos-<architecture>.zip` | Contains `Mediary.app`; open it once to register `stream-mediary://`. |
| Windows x64 | `Mediary-windows-x64.zip` | Extract the full archive and launch `Mediary.exe` once to register `stream-mediary://`. |
| iOS | `Mediary-ios-unsigned.app.zip` | Developer archive only. Sign with your own Apple identity before installing; it is not an installable IPA. |

The desktop archives are not notarized or code signed. macOS and Windows may show an operating-system warning on first launch. The Chrome extension is installed separately from its repository using Chrome's **Load unpacked** action.

Verify downloads with `SHA256SUMS.txt` from this release. Signed video URLs may expire, and some sources require browser-only authorization. DRM-protected streams are not supported.
