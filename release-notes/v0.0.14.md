# Mediary 0.0.14

This release hardens merging, adds folder actions, and fixes desktop layout issues.

## Highlights

- **Self-healing merge.** Corrupt or vanished segments are skipped instead of failing the whole merge — the TS output stays playable with a small gap — and the MP4 remux retries with relaxed error detection (`-err_detect ignore_err`). The result card reports how many segments were skipped.
- **Merge result actions.** "Open containing folder" and "Delete segments" (with confirmation) are now available right on the result card, on every platform.
- **Open download directory from the task menu.** Right-click (desktop) or long-press (mobile) a download task and choose "Open containing directory" — works for finished and in-progress tasks alike.
- **Correct fallback messages.** Windows/macOS no longer claim "MP4 conversion is not supported on mobile" when the real cause is a missing or failing ffmpeg; each reason gets its own hint.
- **Desktop layout fixes.** Title-row actions (Batch import, Clear completed, Pause all) are now flush right instead of stranded mid-row, flow-page primary buttons are right-aligned per the design spec, and desktop buttons are slightly taller (36px).

## Downloads

| Platform | Asset | Notes |
| --- | --- | --- |
| Android arm64 | `Mediary-android-arm64-v8a.apk` | Install on supported Android devices. |
| Android 32-bit ARM | `Mediary-android-armeabi-v7a.apk` | Install on supported Android devices. |
| macOS | `Mediary-macos-<architecture>.zip` | Contains `Mediary.app`; open it once to register `stream-mediary://`. |
| Windows x64 | `Mediary-windows-x64.zip` | Extract the full archive and launch `Mediary.exe` once to register `stream-mediary://`. |
| iOS | `Mediary-ios-unsigned.app.zip` | Developer archive only. Sign with your own Apple identity before installing; it is not an installable IPA. |

The desktop archives are not notarized or code signed. macOS and Windows may show an operating-system warning on first launch.

Verify downloads with `SHA256SUMS.txt` from this release. Signed video URLs may expire, and some sources require browser-only authorization. DRM-protected streams are not supported.
