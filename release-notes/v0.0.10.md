# Mediary 0.0.10

This release adds in-app updates and background downloading on desktop, and fixes resume behavior for PNG-disguised sources.

## Highlights

- **In-app update check.** Mediary looks for new releases at startup (prompting once per version) and from Settings → About. The update dialog shows the changelog, downloads the right package for your platform with resume support and SHA-256 verification, then installs it: the system installer on Android, a Finder reveal on macOS (drag the new app into Applications), and an automatic replace-and-relaunch on Windows.
- **Close to background.** Closing the main window on Windows and macOS now hides it instead of quitting, so downloads keep running. Windows gets a tray icon (left-click restores the window; right-click offers Show/Quit); macOS keeps Mediary in the Dock and clicking it reopens the window.
- **Disguised-source resume fixed.** Pausing or retrying a PNG-wrapped download no longer dies on expired signed URLs — the engine refreshes the playlist, segment and key links from the original source and reuses the segments already on disk.
- **Progress no longer resets.** Pausing a task keeps its progress in the UI and the database, and progress is saved periodically so it survives the app being killed mid-download.
- **Unique default names.** Sources whose URLs carry no meaningful file name (e.g. `.../cdn/master.png`) now default to `host-timestamp` titles instead of colliding on one shared name.

## Downloads

| Platform | Asset | Notes |
| --- | --- | --- |
| Android arm64 | `Mediary-android-arm64-v8a.apk` | Install on supported Android devices. |
| Android 32-bit ARM | `Mediary-android-armeabi-v7a.apk` | Install on supported Android devices. |
| macOS | `Mediary-macos-<architecture>.zip` | Contains `Mediary.app`; open it once to register `stream-mediary://`. |
| Windows x64 | `Mediary-windows-x64.zip` | Extract the full archive and launch `Mediary.exe` once to register `stream-mediary://`. |
| iOS | `Mediary-ios-unsigned.app.zip` | Developer archive only. Sign with your own Apple identity before installing; it is not an installable IPA. |

The desktop archives are not notarized or code signed. macOS and Windows may show an operating-system warning on first launch. The Chrome extension is installed separately from its repository using Chrome's **Load unpacked** action.

Verify downloads with `SHA256SUMS.txt` from this release. Signed video URLs may expire, and some sources require browser-only authorization. DRM-protected streams are not supported.
