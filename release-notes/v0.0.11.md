# Mediary 0.0.11

This release fixes downloads that appear frozen — speed still showing but progress stuck — caused by network requests that could hang forever.

## Highlights

- **No more silent freezes.** Segment, AES key and playlist requests now carry a 30s connect timeout and a 60s idle-receive timeout. A stalled server fails and retries instead of blocking its download slot indefinitely. The receive timeout is an *idle* bound that resets on every received chunk, so slow-but-progressing connections are never cut off.
- **Pause cancels key fetches.** Pausing a task now also aborts an in-flight AES key request, so resuming starts cleanly instead of waiting on a dead connection.

## Downloads

| Platform | Asset | Notes |
| --- | --- | --- |
| Android arm64 | `Mediary-android-arm64-v8a.apk` | Install on supported Android devices. |
| Android 32-bit ARM | `Mediary-android-armeabi-v7a.apk` | Install on supported Android devices. |
| macOS | `Mediary-macos-<architecture>.zip` | Contains `Mediary.app`; open it once to register `stream-mediary://`. |
| Windows x64 | `Mediary-windows-x64.zip` | Extract the full archive and launch `Mediary.exe` once to register `stream-mediary://`. |
| iOS | `Mediary-ios-unsigned.app.zip` | Developer archive only. Sign with your own Apple identity before installing; it is not an installable IPA. |

The desktop archives are not notarized or code signed. macOS and Windows may show an operating-system warning on first launch.

Verify downloads with `SHA256SUMS.txt` from this release. Signed video URLs may expire, and some sources require browser-only authorization. DRM-protected streams are not supported.
