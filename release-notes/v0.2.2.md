# Mediary 0.2.2

This release makes quitting from the Windows tray icon feel instant: the main window disappears immediately and the app exits in about half a second instead of freezing for a couple of seconds.

## Highlights

- **Quit is instant.** Clicking "退出 Mediary" in the tray used to leave the main window on screen and unresponsive for up to ~2 seconds while in-flight downloads were cancelled, and only then exit. The window is now hidden before shutdown starts, and the teardown that stops in-flight downloads is bounded to 400 ms (down from 2 s). Waiting longer was never necessary: a hard exit is already crash-safe because downloads use `.part` files with atomic renames and sqlite runs in WAL mode, so unfinished tasks simply resume next launch.
- **No cancellation storm on the way out.** Disposing the engine cancels every in-flight download, which emits a burst of engine events. The task list now detaches from the database and engine event feeds before that happens, so the widget tree does not try to rebuild from those events while the window is being torn down (which was the other reason the UI appeared frozen).
- **Engine shutdown no longer blocks on listeners.** `DownloadEngine.dispose()` no longer awaits closing its broadcast event stream, which could wait on listeners that were still handling an event during shutdown.

## Downloads

| Platform | Asset | Notes |
| --- | --- | --- |
| Android arm64 | `Mediary-android-arm64-v8a.apk` | Install on supported Android devices. |
| Android 32-bit ARM | `Mediary-android-armeabi-v7a.apk` | Install on supported Android devices. |
| macOS | `Mediary-macos-<architecture>.zip` | Contains `Mediary.app`; open it once to register `stream-mediary://`. |
| Windows x64 | `Mediary-windows-x64.zip` | Extract the full archive and launch `Mediary.exe` once to register `stream-mediary://`. |
| iOS | `Mediary-ios-unsigned.app.zip` | Developer archive only. Sign with your own Apple identity before installing; it is not an installable IPA. |

The desktop archives are not notarized or code signed. macOS and Windows may show an operating-system warning on first launch.

Verify downloads with `SHA256SUMS.txt` from this release. Signed video URLs may expire, and some sources require browser-only authorization. DRM-protected streams are not supported.
