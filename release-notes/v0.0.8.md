# Mediary 0.0.8

This release adds direct support for HLS resources hidden in PNG `roUd` chunks and connects the [Video Stream Link Detector](https://github.com/elementlo/IDM-shell-extension) Chrome extension to Mediary on macOS and Windows.

## Highlights

- Open a detected video source in Mediary or copy its original HTTP(S) address from the extension. Mediary receives the page Referer and browser User-Agent.
- Decode PNG-wrapped master playlists, media playlists, segments, initialization sections, and keys without a local proxy.
- Correctly resolve signed CDN URLs after relative redirects.
- Show clear error messages while keeping detailed exceptions and stack traces in a local rotating log.
- Fix the macOS startup failure that could leave the app on a black screen after opening an extension link.

## Downloads

| Platform | Asset | Notes |
| --- | --- | --- |
| Android arm64 | `Mediary-android-arm64-v8a.apk` | Install on supported Android devices. |
| Android 32-bit ARM | `Mediary-android-armeabi-v7a.apk` | Install on supported Android devices. |
| macOS | `Mediary-macos-<architecture>.zip` | Contains `Mediary.app`; open it once to register `stream-mediary://`. |
| Windows x64 | `Mediary-windows-x64.zip` | Extract the full archive and launch `Mediary.exe` once to register `stream-mediary://`. |
| iOS | `Mediary-ios-unsigned.app.zip` | Developer archive only. Sign with your own Apple identity before installing; it is not an installable IPA. |

The desktop archives are not notarized or code signed for public distribution. macOS and Windows may show an operating-system warning on first launch. The Chrome extension is installed separately from its repository using Chrome's **Load unpacked** action.

Verify downloads with `SHA256SUMS.txt` from this release.

For PNG-wrapped streams, the copied HTTP(S) source must be opened in Mediary; ordinary HLS downloaders cannot decode the PNG payload. Some sources require a fresh signed address or extra authorization headers. DRM-protected streams are not supported.
