# Mediary 0.0.12

This release adds a download proxy, a copy-link context menu on every platform, and total-size display during downloads.

## Highlights

- **Download proxy.** Settings → Download proxy lets you point all download traffic (playlists, segments and AES keys) at a local HTTP proxy, e.g. `127.0.0.1:7890`. Leave it empty for a direct connection. Changes apply the moment you save — no restart needed — and the setting persists across restarts.
- **Copy links from any task.** Right-click a task on macOS/Windows, or long-press on Android/iOS, to copy its download link. Tasks that carry a source web page also offer **Copy source page**, which copies the web page the stream came from.
- **Total size while downloading.** Task cards now show `downloaded / total`. Byte-range playlists report an exact total up front; other playlists show a running estimate, and the total is hidden when it cannot be determined.
- **Smarter default names.** Image-disguised playlists with generic names (`index.jpg`, `master.jpeg`, …) no longer all share one title — JPG/JPEG/WebP/GIF disguises are recognized like PNG and fall back to a unique `host-timestamp` name.

## Downloads

| Platform | Asset | Notes |
| --- | --- | --- |
| Android arm64 | `Mediary-android-arm64-v8a.apk` | Install on supported Android devices. |
| Android 32-bit ARM | `Mediary-android-armeabi-v7a.apk` | Install on supported Android devices. |
| macOS | `Mediary-macos-<architecture>.zip` | Contains `Mediary.app`; open it once to register `stream-mediary://`. |
| Windows x64 | `Mediary-windows-x64.zip` | Extract the full archive and launch `Mediary.exe` once to register `stream-mediary://`. |
| iOS | `Mediary-ios-unsigned.app.zip` | Developer archive only. Sign with your own Apple identity before installing; it is not an installable IPA. |

The desktop archives are not notarized or code signed. macOS and Windows may show an operating-system warning on first launch.

Verify downloads with `SHA256SUMS.txt` from this release. Signed video URLs may expire, and some sources require browser-only authorization. DRM-protected streams are not supported.
