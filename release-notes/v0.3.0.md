# Mediary 0.3.0

This release adds an emoji picker to the message board, ships a brand-new project website, and gives the whole app a visual refresh with the low-saturation "Soft Iris" purple palette and matching icons.

## Highlights

- **Emoji on the message board.** The compose/reply sheet now has an emoji button that opens a built-in picker with six curated categories — no external dependency. Emoji insert at the caret, so you can add several in a row. On phones the soft keyboard steps aside first so the panel takes its place instead of pushing the sheet off-screen; on desktop the panel is width-capped and centered. Tap back into the text field to dismiss it.
- **A new look: Soft Iris.** The indigo brand color is replaced by a calm, low-saturation purple across the UI, with every semantic color (success, warning, accent, danger) retuned to sit beside it. The "downloading" accent is a slate teal kept far enough from the purple that the two active states stay distinguishable at a glance. Launcher and tray icons are redrawn as a matching gradient.
- **Project website.** Mediary now has a bilingual (中文 / English) website built with Astro: hero, features, screenshots, download, browser-extension and FAQ sections. It is pure static HTML with zero runtime JavaScript, image-optimized, and fully SEO-ready (hreflang, Open Graph, structured data, sitemap).
- **Smoother cards.** Fixed a Flutter debug assertion where ink splashes on list rows inside cards could be hidden by the card background; ripples now render correctly.

## Downloads

| Platform | Asset | Notes |
| --- | --- | --- |
| Android arm64 | `Mediary-android-arm64-v8a.apk` | Install on supported Android devices. |
| Android 32-bit ARM | `Mediary-android-armeabi-v7a.apk` | Install on supported Android devices. |
| macOS | `Mediary-macos-<architecture>.zip` | Contains `Mediary.app`; open it once to register `stream-mediary://`. |
| Windows x64 | `Mediary-windows-x64.zip` | Extract the full archive and launch `Mediary.exe` once to register `stream-mediary://`. |
| iOS | `Mediary-ios-unsigned.app.zip` | Developer archive only. Sign with your own Apple identity before installing; it is not an installable IPA. |

The desktop archives are not notarized or code signed. macOS and Windows may show an operating-system warning on first launch.

Verify downloads with `SHA256SUMS.txt` from this release. Signed video URLs may expire, and some sources require browser-only authorization. DRM-protected streams are not supported.
