# Mediary 0.2.1

This release fixes two issues: a lingering command-prompt window after the Windows in-app update, and downloads stuck in the "merging" state by older builds.

## Highlights

- **No leftover console window after a Windows update.** Installing an update used to leave a minimized command-prompt window open showing "找不到批处理文件" (batch file not found), and closing that window also quit the freshly updated app. The installer batch deleted itself with a bare `del`, which made cmd fail to read the next line and keep the console alive; the relaunched app was a child of that console, so closing it killed the app too. The script now ends the batch context cleanly before deleting itself, so the window closes on its own and the app keeps running.
- **Stuck "merging" downloads are recovered on startup.** An older build with no disk-full detection could hang the merge when the disk filled up, leaving the task persisted as "merging". After a restart it had no runtime, stayed in the downloads list forever, and offered no way to cancel or delete it. Such stale records are now cold-resumed at startup: the merge retries using the already-downloaded segments, and if the disk is still full the task pauses into a recoverable state with a "disk full — free up space then resume" banner and working actions.

## Downloads

| Platform | Asset | Notes |
| --- | --- | --- |
| Android arm64 | `Mediary-android-arm64-v8a.apk` | Install on supported Android devices. |
| Android 32-bit ARM | `Mediary-android-armeabi-v7a.apk` | Install on supported Android devices. |
| macOS | `Mediary-macos-<architecture>.zip` | Contains `Mediary.app`; open it once to register `stream-mediary://`. |
| Windows x64 | `Mediary-windows-x64.zip` | Extract the full archive and launch `Mediary.exe` once to register `stream-mediary://`. |
| iOS | `Mediary-ios-unsigned.app.zip` | Developer archive only. Sign with your own Apple identity before installing; it is not an installable IPA. |

The desktop archives are not notarized or code signed. macOS and Windows may show an operating-system warning on first launch.

Verify downloads with `SHA256SUMS.txt` from this release. Signed video URLs may expire, and some sources require browser-only authorization. DRM-protected streams are not supported.
