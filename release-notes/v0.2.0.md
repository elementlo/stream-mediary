# Mediary 0.2.0

This release adds graceful disk-full handling, manual ffmpeg path configuration, and fixes the Windows tray quit hang.

## Highlights

- **Disk-full no longer kills your download.** When the disk fills up mid-download or mid-merge, the task now pauses and keeps its progress instead of failing with a generic error. The downloads list shows a "disk full — free up space then resume" banner, and a system notification fires for background downloads. Merging also pre-flights available space so it stops before writing a truncated file. Free up space (or pick another save folder) and tap Resume to continue from where it left off.
- **Set the ffmpeg path yourself.** Settings → ffmpeg now has a path field with a Browse picker, validated before saving. Desktop detection also probes common Windows install locations (Program Files, chocolatey, scoop, winget) in addition to PATH.
- **macOS ffmpeg detection works.** The App Sandbox is disabled so the app can run an ffmpeg binary outside its bundle; previously detection always failed on macOS.
- **Windows tray "Quit" exits promptly.** Quitting from the tray no longer leaves the main window hanging for several seconds after the icon disappears.

## Downloads

| Platform | Asset | Notes |
| --- | --- | --- |
| Android arm64 | `Mediary-android-arm64-v8a.apk` | Install on supported Android devices. |
| Android 32-bit ARM | `Mediary-android-armeabi-v7a.apk` | Install on supported Android devices. |
| macOS | `Mediary-macos-<architecture>.zip` | Contains `Mediary.app`; open it once to register `stream-mediary://`. |
| Windows x64 | `Mediary-windows-x64.zip` | Extract the full archive and launch `Mediary.exe` once to register `stream-mediary://`. |
| iOS | `Mediary-ios-unsigned.app.zip` | Developer archive only. Sign with your own Apple identity before installing; it is not an installable IPA. |

The desktop archives are not notarized or code signed. macOS and Windows may show an operating-system warning on first launch.

Verify downloads with `SHA256SUMS.txt` from this release. Signed video URLs may expire, and some sources require browser-only authorization. DRM-protected streams are not supported.
